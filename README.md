# Online Shopping and Order Management System

## Project Description
A web-based application for customers to browse products, manage shopping carts, and place orders. Administrators can manage the product catalogue.

## Features
- Customer registration
- Product catalogue and search
- Add and remove cart items
- Checkout and order placement
- Stock management
- Admin product management (add, edit, delete)
- Order management

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Testing: Node.js Test Runner, Selenium
- Containerization: Docker
- CI/CD: Jenkins
- Version Control: Git and GitHub

## Run Locally
1. Install Node.js.
2. Install dependencies:
   npm install
3. Start the application:
   npm start
4. Open http://localhost:3000

## Run Tests
npm test
